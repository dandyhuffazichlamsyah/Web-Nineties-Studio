Kapan sebaiknya melakukan booking?
Disarankan H-14 hingga H-30 sebelum hari-H, terutama untuk akhir pekan dan musim wisuda.

Berapa DP untuk mengunci tanggal?
DP sebesar 30% dari total nilai paket. Pelunasan dilakukan setelah sesi selesai pada hari-H.

Bagaimana penyerahan file foto?
Seluruh file mentahan (RAW) diberikan maksimal H+2 via Google Drive, dan hasil edit selesai 7-14 hari kerja.
